# Polices Custom - Urbanist & Satoshi Variable

## Instructions d'ajout

1. **Téléchargez les fichiers de polices** depuis Figma ou Google Fonts

2. **Placez les fichiers** dans ce dossier (`assets/fonts/`) avec les noms exacts suivants :

### Urbanist
- `Urbanist-Regular.ttf`
- `Urbanist-Medium.ttf`
- `Urbanist-SemiBold.ttf`
- `Urbanist-Bold.ttf`

### Satoshi Variable
- `Satoshi-Regular.otf`
- `Satoshi-Medium.otf`
- `Satoshi-Bold.otf`

3. **Décommentez le code** dans `src/hooks/useFonts.ts` une fois les fichiers ajoutés

4. **Redémarrez l'app** avec `npm start`

## Sources recommandées

- **Urbanist**: [Google Fonts](https://fonts.google.com/specimen/Urbanist)
- **Satoshi Variable**: Disponible sur [Fontshare](https://www.fontshare.com/fonts/satoshi) ou depuis votre compte Figma
